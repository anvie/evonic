General

Core behavior, model routing, and reliability tuning. Changes save automatically.

Appearance

Theme
Light, dark, or follow your system preference.
Agent Sidebar Limit
Maximum number of agents shown in the sidebar. Range: 1–500.

Models & Routing

Default LLM Model
Global default model for all agents and evaluations.
Default Model Fallback
Backup model used when the global default model fails.

Configure the primary model and fallback order for image descriptions.

Vision Model (Primary)
First vision-capable model used by the describe_image tool. Only models with vision support are listed.
Vision Fallback 1
First backup model used when the primary vision model fails.
Vision Fallback 2
Second backup model used when the primary model and Fallback 1 fail.
KB Organizer Model
Model used by the KB Organizer background sub-agent that files conversation knowledge into each agent's memory vault. Defaults to the agent's own model when unset.
KB Organizer Schedule
Daily time for the Vault Janitor to organize active agents' memory vaults. Changes apply immediately. Default: 03:00.
Task Classifier
Automatically classify tasks as trivial or complex. Trivial tasks skip planning and execute directly.
Task Classifier Model
Model used for task classification. Small, fast models work well.
Path Detection Model (CMP)
Model used by Context Memory Path for task-boundary decisions (continue / return / branch) and path card summarization. Accuracy here decides when a new session path is opened — a stronger model is recommended if path switching misfires.

Agent Behavior

Message Wrapper
Prepends a brief instruction to each user message, prompting agents to scan it for preferences, instructions, and personal facts before replying. Recommended for personal assistant agents; can be overridden per-agent in Advanced Settings.
Max Tool Iterations
Maximum tool-call iterations per agent turn and per evaluation. Prevents infinite loops in multi-step reasoning. Range: 1–1000.
Long-Running Command Detection
Detect and block build/compile commands (make, cargo, npm build, …) that may exceed the bash timeout. When disabled, all commands run directly.

Reliability & Concurrency

Agent Timeout Retries
Automatic retries when the LLM times out mid-reasoning during chat. 0 disables auto-retry.
LLM Max Retries
Maximum retry attempts on transient LLM errors (timeout, 5xx), with exponential backoff (2s, 4s, 8s…). 0 disables.
Max Concurrent Turns per Agent
Maximum parallel queries per agent (from different sessions). 0 = unlimited.
Max Concurrent Turns per Model
Global default for all models (used when a model's own limit is 0). 0 = unlimited.
Max Concurrent LLM (Global)
Hard cap on simultaneous LLM calls across all agents and models. 1 = serialised (default, safest for shared API keys). Increase only if your provider allows concurrent calls.
Agent Queue Workers
Worker threads processing agent messages. Increases take effect immediately; decreases require a restart. Range: 1–32.

WhatsApp Safe Delivery

Safe Delivery
Queue and pace outbound WhatsApp messages to reduce bursty delivery.
Pooling Window
Merge intermediate output arriving within this window before sending. Range: 0.1–30 seconds.
Minimum Send Interval
Minimum time between messages to the same chat. Range: 0.1–60 seconds.
Typing Speed
Characters per second used to estimate typing delay. Range: 1–100.
Maximum Typing Delay
Cap the calculated typing delay for a single response. Range: 1–120 seconds.
Outbound Limit per Minute
Per-channel rolling quota. Delivery pauses and requeues when this limit is reached. Range: 1–600.
Natural Text Formatting
Normalize Markdown-heavy responses into WhatsApp-friendly conversational text.
