DMSS mode
Not used while the policy is “HMADS only” (effective mode: off).

How a command is decided

  1. Agent runs a command bash or python tool call
  2. HMADS scores it Deterministic rules, always run Only when the DMSS decision is unusable
  3. DMSS model evaluates it Skipped — the provider is never called Recorded and compared only Its decision is used when usable
  4. HMADS decision applied DMSS decision applied A command is never left undecided
Deterministic HMADS fallback

When DMSS is enabled, the HMADS decision is applied instead if:

  • the call times out (request_timeout_ms)
  • the circuit breaker is open
  • the decision is malformed, or confidence is below minimum_confidence

Identical inputs always produce identical outcomes.

Enforce behaviour
In enforce mode an allowed command is stored in the activity table only while this is on. Refusals are always recorded. Turning it off leaves no trace of what the model cleared.
